# END NF 신경섬유종증 안내 챗봇

신경섬유종증(Neurofibromatosis) 환자와 가족을 위한 정보 안내 챗봇입니다.

## 주요 기능

- **질환 정보**: NF1 정의, 증상, 진단 기준
- **부모 가이드**: 자녀와의 대화법, 연령별 조언
- **학교생활 안내**: 교직원 가이드, 학교 적응 지원
- **복지 혜택**: 산정특례, 의료비 지원, 장애 등록
- **학교폭력 대처**: 괴롭힘 예방, 신고 절차
- **도움 연락처**: 관련 기관 연락처 모음

## 사용 방법

웹 브라우저에서 바로 접속하여 사용할 수 있습니다.

## 자료 출처

- 질병관리청 KDCA - 교직원을 위한 소아청소년 다빈도 희귀질환 안내서 (신경섬유종증)
- END NF 신경섬유종증 환우회 - 부모와 아이들을 위한 가이드
- 희귀·난치성 질환 환자를 위한 복지정보 (2024)
